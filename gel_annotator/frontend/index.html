About
Slots Gel Annotator is a vector-native, browser-based tool for annotating gel-electrophoresis images.
References & methods
Image processing
RGB → grayscale via channel-max (preserves imager-baked red saturation contours from Bio-Rad GelDoc / Azure / GE imagers).
Auto-stretched LUT — central 98 % of the histogram (p1 .. p99.5) is mapped to the 0..255 display range.
Saturation overlay — pixels at ≥ 99.5 % of the source dynamic range are flagged in red. Threshold is relative to the raw range (not the LUT) so it tracks the imager's intent.
Automatic band detection
The Auto-detect bands button collapses the selected ladder lane to a 1-D vertical intensity profile (mean across the lane's width) and finds band centers in three steps:
Identify all strict local maxima along the profile.
Score each maximum by its topographic prominence — the height above the lowest valley reached before encountering a higher peak (or the signal's edge) on either side. Keep only peaks whose prominence is at least 3 % of the profile's dynamic range, which rejects shoulders, gel speckle, and noise floor variation.
Enforce a minimum 5-pixel separation between kept peaks via a greedy pass that prefers the higher-prominence peak whenever two would otherwise sit within the exclusion radius.
The implementation is pure-NumPy and runs entirely on the collapsed 1-D profile, so even very tall gels finish in a fraction of a millisecond.
Build & runtime
Backend: FastAPI + uvicorn (Starlette ASGI), NumPy, Pillow, tifffile, SciPy.
Frontend: vanilla JavaScript + SVG (no framework). One single-page HTML file served from gel_annotator/frontend.
Branding: favicon & desktop icon generated with favicon.io.
